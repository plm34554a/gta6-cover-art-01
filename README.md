Vice Panels is an offline poster cover maker in the GTA style: load your own photos, arrange them across slanted multi-panel collage layouts, drag and zoom each panel's framing, apply Vice City colour grades, set a bold caption, and export the finished cover as a PNG at 1080x1080, 1080x1350 or 1920x1080. Fully static, no build step, no network at runtime, and no Rockstar artwork, logos or fonts.

## Run it

```sh
node serve.ts
```

Then open the local address it prints in a desktop browser. To produce the hand-in output instead: `MAKEFUN_OUTPUT_DIR=out node main.ts`.
